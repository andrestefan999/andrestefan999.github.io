# Andre Tutoring

**Website:** [https://andremtutoring.com](https://andremtutoring.com)

A responsive website for Andre Tutoring, providing online tutoring for NSW high school students in HSC Physics and Mathematics.

## Overview

Andre Tutoring offers personalised online tutoring, specialising in the NSW Mathematics and Physics curricula.

The website provides information about tutoring services, subject-specific resources, study strategies, pricing and contact details.

## Tutoring Subjects

- **HSC Physics** – NSW Physics curriculum and examination preparation
- **Mathematics Advanced** – Year 11 and 12 Mathematics Advanced
- **Mathematics Extension 1** – Extension 1 curriculum and problem-solving
- **Mathematics Extension 2** – Advanced mathematical concepts and examination preparation
- **Junior Mathematics** – Mathematics support for younger students

## Website Features

- Responsive layouts for desktop, tablet and mobile devices
- Dedicated pages for individual tutoring subjects
- Subject-specific curriculum information
- Study tips and time-management resources
- Downloadable educational resources and past papers
- Interactive calendar widget
- Expandable accordion sections
- Smooth scrolling and page transitions
- Animated buttons, cards and interactive elements
- Optimised images using modern formats such as WebP and AVIF
- Custom colour themes and consistent styling
- Contact and enquiry information

## Hosting and Deployment

The website is hosted using **GitHub Pages** and connected to a custom domain.

[https://andremtutoring.com](https://andremtutoring.com)

The repository uses GitHub Actions for its static website deployment workflow.

Changes pushed to the configured deployment branch are published through GitHub Pages.

The `CNAME` file configures the custom domain, while `sitemap.xml` and `robots.txt` support search engine discovery and indexing.

## Local Development

The website uses standard HTML, CSS and JavaScript and does not require a build process.

To run the website locally:

1. Clone the repository:

   ```bash
   git clone https://github.com/andrestefan999/andrestefan999.github.io.git
   ```

2. Open the repository folder in your preferred code editor.

3. Open `index.html` in a browser or use the VS Code Live Server extension.
